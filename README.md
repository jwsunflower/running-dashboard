# 러닝 로그 · COROS 대시보드

2026 시즌 러닝 기록을 COROS Training Hub에서 옮긴 개인용 정적 대시보드입니다.
GitHub Pages: https://jwsunflower.github.io/running-dashboard/

- 2026-01-01 ~ 2026-11-21 러닝 174회 (야외 127 / 트레드밀 47), 1,343.9 km
- 월간·주간 거리, 월별 평균 페이스, 개인 최고 기록, 레이스 예측
- GPS 경로 지도: Leaflet + Esri Dark Gray 타일, 러닝을 누르면 해당 경로로 확대
  - COROS 대량 내보내기(TCX)의 2026 야외 러닝에서 경로를 복원해 **122건** 수록
    (800 m 미만 조각 기록 5건 제외). 경로 데이터는 `routes.json`으로 분리해
    `index.html`은 75 KB로 가볍게 유지하고, 지도가 필요할 때 한 번만 받아옵니다.
- 개인정보: 이름·연락처·좌표 텍스트는 게시하지 않으며, 경로는 시작·종료 지점 약 260 m를 잘라 표시합니다.
- 데이터 출처: COROS Training Hub(2026-11-21 활동까지) + COROS 스포츠 데이터 내보내기(2026-11-21 생성).
  EvoLab 회복도·피트니스는 2026-11-22 오전 값. 지어낸 수치는 없습니다.
