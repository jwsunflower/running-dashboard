# Running Log · COROS Dashboard

A small, mobile-first running dashboard built from my own COROS Training Hub data.

**Live:** https://jwsunflower.github.io/running-dashboard/

## What's on it

- **Latest run** — distance, pace, moving time, avg HR, training load
- **Readiness** — recovery %, hours to full recovery, overnight HRV vs. normal range, base fitness, running fitness / VO₂ max
- **Weekly volume** — last 8 weeks (Mon–Sun), with session counts
- **Pace trend** — average pace of the last 14 sessions
- **Last 4 weeks** — distance, training load, time, sessions, avg HR
- **Recent runs** — 40 sessions (8 Sep – 21 Nov 2026), filterable outdoor / treadmill
- **Best efforts & race predictor** — COROS personal records and race estimates

## Notes

- Every number comes from COROS Training Hub as observed on **21 Nov 2026**. Nothing is estimated or generated.
- Location labels are the coarse activity names COROS records (Seoul / Incheon / Seongnam / Fukuoka / Treadmill). No personal details, accounts, or coordinates are published here.
- Single static `index.html` — no framework, no external CDN, charts drawn as inline SVG.
